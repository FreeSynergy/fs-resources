# fs-resources

FreeSynergy program that answers: what do we have, what do we need, and who has time? People keep control over their own time.

* `crates/fs-resources-core`: the program core (no GUI, no capnp server yet). See `DESIGN.md`.
* The contract is `resources.capnp` in [fs-interfaces](https://github.com/FreeSynergy/fs-interfaces) (tag v0.20.0).
